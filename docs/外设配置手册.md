# 外设配置手册 (按 control_task 执行路径)

**MCU**: STM32F40xxx | **主频**: 168 MHz | **APB1**: 42 MHz | **APB2**: 84 MHz

---

## 执行路径总览

```
TIM6 @1kHz
 └─ TIM6_DAC_IRQHandler
     └─ control_task()
         ├─ Chassis_Omnidir_Wheel_Fdb_Set()    ← 读取 CAN2 编码器反馈
         ├─ get_desired_mode()                  ← 目标模式 (来自遥控器/任务)
         ├─ update_data() / run_*(mode)         ← 运动控制
         └─ can_bus_send_task()
             └─ Set_C620andC610_IQ1(CAN2, ...)  → CAN2 发送电流指令
```

## 2. CAN2 — 底盘电机总线 (唯一活跃数据流)

### 接收路径 (中断驱动)

```
CAN2_RX0_IRQHandler                     ← 抢占3, 响应3
  └─ Can2ReceiveMsgProcess()            ← CanBus.c:48
      ├─ CM1Encoder_MOTOR (0x201)
      │   └─ M3508orM2006EncoderTask(&Driving_Encoder[0])
      ├─ CM2Encoder_MOTOR (0x202)
      │   └─ M3508orM2006EncoderTask(&Driving_Encoder[1])
      ├─ CM3Encoder_MOTOR (0x203)
      │   └─ M3508orM2006EncoderTask(&Driving_Encoder[2])
      └─ CM4Encoder_MOTOR (0x204)
          └─ M3508orM2006EncoderTask(&Driving_Encoder[3])
```

### CAN2 参数

| 参数 | 值 |
|------|-----|
| RX 引脚 | **PB12** (AF9) |
| TX 引脚 | **PB13** (AF9) |
| 模式 | Normal |
| ABOM | ✓ |
| BS1/BS2/SJW | 9/4/1 tq |
| 预分频 | 3 |
| **波特率** | **1 Mbps** (42M/14/3) |
| 滤波器 | 编号14, 32bit ID掩码, FIFO0, 全通 |

### 发送路径 (control_task 主动调用)

```
control_task() → can_bus_send_task()
  └─ Set_C620andC610_IQ1(CAN2, Chassis.Pid_Speed[0..3].out)
      → CAN ID 0x200, 4路电流 (int16_t)
```

### CAN2 总线设备

| 设备 | CAN ID | 电机 | 用途 |
|------|--------|------|------|
| CM1 (驱动轮1) | 0x201 | M3508/M2006 | 右前 |
| CM2 (驱动轮2) | 0x202 | M3508/M2006 | 左前 |
| CM3 (驱动轮3) | 0x203 | M3508/M2006 | 左后 |
| CM4 (驱动轮4) | 0x204 | M3508/M2006 | 右后 |
| C620 控制指令 | 0x200 | — | 发送 4 路 iq 电流 |

**应用层编码器**: `Omni_wheel_chassis.Driving_Encoder[0..3]` (全向轮结构)

## 4. USART6 — CH100 IMU (被动输入)

```
USART6_IDLE IRQ → CH100_getDATA() → gimbal_gyro
                                    → control_task 中用于偏航角反馈 (注释段)
```

| 参数 | 值 |
|------|-----|
| RX 引脚 | **PC7** (AF8) |
| TX 引脚 | **PC6** (AF8) |
| **波特率** | **921600** |
| 缓冲 | 单缓冲 (100 字节) |
| RX DMA | **DMA2_Stream1** / Ch5 / Normal / Medium |
| IDLE IRQ | USART6_IRQn (抢占3, 响应3) |

### CH100 数据结构

```c
typedef struct {
    float pitch_Angle;   // 俯仰角
    float yaw_Angle;     // 偏航角
    float roll_Angle;    // 横滚角
    float pitch_Gyro;    // 俯仰角速度
    float yaw_Gyro;      // 偏航角速度
    float roll_Gyro;     // 横滚角速度
    float x_Acc, y_Acc, z_Acc;
} general_gyro_t;       // 实例: gimbal_gyro
```

## 6. 控制器

**文件**: `APP/RTOS/Src/control_task.c`

### PID 参数 (control_task_Init)

| PID 对象 | 类型 | Kp | Ki | Kd | I限幅 |
|----------|------|----|----|----|-------|
| `pid_vw` | POSITION_PID | 3 | 0 | 0.34 | 0 |
| `pid_yaw_angle` | POSITION_PID | 5 | 0 | 0.5 | 0 |
| `pid_vw_only` | POSITION_PID | 30 | 1 | 0.7 | 0.1 |

### 控制模式

```
target_mode → switch:
  MODE_ANGLE_FOLLOW    → run_angle_follow()
  MODE_SPEED_RAMP      → run_speed_ramp()
  MODE_TRIANGLE_WAVE   → run_triangle_wave()
  MODE_AUTO_TRANSLATE  → run_auto_translate()
  默认                 → run_stop()
```

### NVIC 优先级 (实际启用的中断)

| 中断 | 抢占 | 响应 | 用途 |
|------|------|------|------|
| USART1_IRQn | **0** | 0 | DBUS 遥控 (IDLE) |
| CAN2_RX0_IRQn | 3 | 3 | 底盘电机反馈 |
| CAN2_TX_IRQn | 3 | 3 | CAN2 发送完成 |
| USART6_IRQn | 3 | 3 | CH100 IMU (IDLE) |
| **TIM6_DAC_IRQn** | **3** | **2** | **1ms 控制循环** |
